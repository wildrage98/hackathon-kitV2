# quiz-prep

코드를 고치지 않는다. 저장소에 있는 사실만 쓴다.

## 순서
1. `python3 tools/quiz_prep.py --project <이름>` 출력(훅 상태, 남은 `(채움`)과 `docs/QUIZ_CARD.md`(파일·테스트·API·환경변수·명령·숫자·로그)를 읽는다.
2. 6유형마다 질문 1개 — 평가자처럼 **내 문서의 문장을 그대로 인용**해서 만든다:
   ① 구조 선택(결정·대안·제약) ② 입력→화면 흐름(모듈 책임·상태 위치) ③ 검증함/가정함/미구현 + 확인 경로
   ④ 실패 경로 vs 정상(오류 적용 / 적용 후 미재생성 / 실행 중 재요청) ⑤ 조건 변경 예측·병목·AI 없이 확인 ⑥ AI 산출물 수용/수정/폐기 + 근거
3. 답 500자: 결론 1문장 → 근거(파일·테스트명·숫자) → 대안과 버린 이유 → 제약/한계. 근거를 못 찾은 주장은 `[근거 없음 — 문서 또는 테스트 보강 필요]`.
4. `docs/QUIZ.md` 를 그 양식 그대로 덮어쓴다. 맨 아래 암기 카드: 파일 5 · 테스트 5 · 숫자 5 · 명령 3 · 한계 3.
5. 보고: docs/QUIZ.md 경로 + [근거 없음] 목록 + 빈 훅 목록. 문서를 고치는 건 사용자가 한다.

## 금지
- 질문 6개 초과, 코드·문서 수정, 저장소에 없는 수치·파일명, "통과했다"를 로그 없이 쓰기
