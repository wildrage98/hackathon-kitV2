# 11. 오버레이(층간 정렬 오차) 불량 원인 분석

`10-fab.md` F형(수율·불량 원인)의 오버레이 전용판. 뼈대는 같다: CSV 검증·적용 → **판정 규칙 검증기** → 가장 단순한 판정 → 성분 분해 → 요인 순위 → 화면·내보내기.
모듈: `kitlib/overlay.py`(성분 분해·지표·flyer·벡터맵) + `kitlib/groupstats.py`(요인 순위) + `spc` + `svgchart` + `report`.

## 어휘
| 말 | 뜻 |
|---|---|
| 오버레이 (OVL) | 현재 레이어 패턴이 **기준(이전) 레이어**에 대해 어긋난 양. 사이트마다 dx, dy (보통 nm) |
| ADI / AEI | 현상 후 계측(불량이면 감광막 벗기고 재노광 = 재작업 가능) / 식각 후 계측(재작업 불가) |
| 사이트 / 필드(샷) | 웨이퍼 위 계측 위치 / 한 번에 노광되는 영역. 사이트 좌표 = 웨이퍼 좌표 또는 필드 중심 + 필드 내 좌표 |
| 웨이퍼 성분 | 평행이동 Tx·Ty / 배율 Mx·My / 회전 Rx·Ry (회전 = 평균, 직교성 = 차이) |
| 필드 내 성분 | 필드 배율 mx·my / 필드 회전 rx·ry (레티클·렌즈 쪽) |
| 잔차 / 고차 | 선형 모델이 설명 못 하는 나머지 (공정 변형·가장자리·계측) |
| \|mean\|+3σ | 대표 판정 지표. **X, Y 따로** |
| 척 (chuck) | 노광 장비 안 웨이퍼 테이블 (장비당 1~2개) |
| APC / R2R | 이전 로트 계측으로 다음 로트 보정값을 정하는 제어 |
| 레티클 | 마스크 |
| flyer | 마크 손상·계측 오류로 혼자 튀는 사이트 |

## 담당자에게 먼저 (기준)
1. **불량 정의** — 레이어별 spec, 지표(\|mean\|+3σ / max / 잔차 3σ), X·Y 각각?, spec 과 같으면 불량?, 웨이퍼 단위? 로트 단위?
2. **ADI 인가 AEI 인가** — ADI 면 식각 전에 잡아 재작업하는 것이 가치
3. **기준 레이어 정보** — 기준 레이어의 노광 장비·척·레티클이 데이터에 있나 (오버레이 = 두 레이어 차이)
4. **무엇이 더 비싼가** — 노광 장비 점검·정지(오탐) vs 불량 로트 진행(미탐)
5. **결과를 누가 어떻게 쓰나** — 장비 점검 / 보정값 수정 / 재작업 대상 선정
6. **재작업 웨이퍼** — 계측 2회: 최종만? 둘 다?
7. **flyer 기준** — 있으면 그대로. 없으면 제안: 중앙값 ± 5·MAD(×1.4826), 제거 수 기록
8. **좌표 단위·부호 규약** (mm/nm, 회전 부호) · 이미 아는 원인 · 제외 기간 · 최근 사례 1개

## 원인 축 ↔ 시그니처 ↔ 필요한 컬럼
| 원인 | 시그니처 | 컬럼 |
|---|---|---|
| 노광 장비 / 척 | 특정 장비·척에서만 높음. 현재 레이어 장비 ≠ 기준 레이어 장비 조합(매칭)에서 나빠짐 | 노광 장비, 척, 기준 레이어 장비·척 |
| 레티클 | 필드마다 같은 패턴 반복, 필드 내 성분 큼, 레티클 교체 시점부터 | 레티클 ID, 교체 이력 |
| 보정(APC) | 평행이동·배율이 한쪽으로 치우침(평균 편향), PM·교체 직후 첫 로트 | 적용 보정값, 이벤트 이력 |
| 공정 유발 변형 (증착 응력·CMP·열처리) | 가장자리·방사형, 고차 잔차 큼 | 이전 스텝 장비·챔버 |
| 계측 | 사이트 몇 개만 튐, 계측 장비별 차이 | 계측 장비, 사이트 좌표, 측정 품질값 |
| 시간 | 특정 시점 이후 drift | 노광 시각, 이벤트 시각 |

## 순서 (최소 실행본 → 확장)
1. **판정만**: 사이트 → 웨이퍼별 X/Y \|mean\|+3σ → spec 판정. 판정은 생성 코드와 별도 검증기로 다시 센다
2. **정제**: `flag_flyers` → 제거 수·위치를 결과에 남긴다
3. **성분 분해**: `fit_linear(model="wafer6")` → 필드 내 좌표가 있으면 `wafer10` → 성분·잔차 3σ
4. **요인 순위**: 웨이퍼(또는 로트) 요약 행에 컨텍스트 컬럼 붙여 `groupstats.rank_factors(..., min_n=)`
5. **교란 확인**: 제품별로 나눠도 같은 순위인가, `crosstab(장비 × 제품)`
6. **시간**: 이벤트 전후 비교, 장비별 `spc.imr_limits` 관리도
7. **산출**: 의심 순위 + 근거(불량률·lift·n·chi2) + 우세 성분 + 벡터맵 + 권고 조치 + 재현 명령

## 성분 → 의심 원인 (후보 — 담당자 확인)
| 우세 성분 | 후보 |
|---|---|
| 평행이동 Tx·Ty | 정렬, 보정값 |
| 배율 Mx·My | 열(웨이퍼 팽창), 보정값 |
| 회전·직교성 Rx·Ry | 웨이퍼 로딩·정렬, 스테이지 |
| 필드 내 mx·my·rx·ry, 필드 반복 패턴 | 레티클, 렌즈 |
| 가장자리·고차 잔차 | 증착 응력·CMP·열처리 변형, 척 가장자리 |
| 특정 척만 | 척 |
| 사이트 몇 개만 | 계측(flyer), 마크 손상 |
평균이 치우치면 보정 문제, 산포가 크면 장비·공정 불안정 — 3σ 하나로 합치지 않는다.

## 지표
- 웨이퍼별: n, flyer 수, X/Y \|mean\|+3σ(원값), X/Y 잔차 3σ, 성분 6(10)개, 판정
- 요인별: 불량률, lift, n, chi2, worst 그룹
- 조건 변경: spec a→b 일 때 불량 웨이퍼 수, 1위 요인 유지 여부

## 함정
- 점수만 있고 근거(숫자·맵)가 없음
- 표본 적은 그룹이 1위 → `min_n`
- 기준 레이어 무시
- 평균·산포 섞기, X/Y 합치기
- 재작업 웨이퍼 중복 계측
- 좌표 단위·부호 규약 섞임
- flyer 를 원인으로 오판 / 반대로 flyer 제거로 진짜 불량을 숨김 → 제거 수·위치 기록
- 계측하지 않은 필드(샘플링)를 0 으로 취급

## 코드
```python
from kitlib import csvio, overlay, groupstats, report
rows, _ = csvio.read_csv("data/overlay_sites.csv")            # wafer, x, y, dx, dy (+ fx, fy, 컨텍스트)
summ = overlay.wafer_summary(rows, wafer_col="wafer", spec=SPEC, flyer_k=5,
                             keep_cols=["lot", "exp_tool", "chuck", "reticle", "ref_tool", "ref_chuck"])
rank = groupstats.rank_factors(summ, ["exp_tool", "chuck", "reticle", "ref_tool", "ref_chuck"],
                               flag=lambda r: r.get("fail"), min_n=5)
top = overlay.contributions(summ[0], radius=150, residual_3s=summ[0].get("res_x_3s"))   # [{term, size, hint}]
svg = overlay.vector_map_svg([r for r in rows if r["wafer"] == summ[0]["wafer"]], title=summ[0]["wafer"])
```
`overlay.py` 머리말에 모델 식·단위. 성분 분해는 dx 식과 dy 식이 독립이라 축별 3(5)개 미지수 최소제곱.

## 확인 문제·발표 문장 (그렇게 만들었을 때만)
- 구조 선택: "spec 판정과 원인 순위를 분리했다. 판정은 생성 코드와 별도 검증기가 다시 센다."
- 성분 분해: "선형 성분 분해는 로봇 좌표계 캘리브레이션과 같은 문제다 — 측정점 쌍에서 평행이동·회전·스케일을 최소제곱으로 추정하고 잔차를 따로 봤다."
- 실패 경로: "측정점이 부족하거나 한 줄 위에 있으면 성분 분해를 하지 않고 fit_error 로 표시한다. 판정(\|mean\|+3σ)은 계속 낸다."
- 조건 변경: "spec 을 a→b 로 바꾸면 불량 웨이퍼 n→m, 1위 요인은 (유지/변경)."
