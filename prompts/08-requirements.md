# 08 — 요구사항 매트릭스 (서비스형, README 읽은 직후)

```
README.md 의 요구사항을 docs/REQUIREMENTS.md (템플릿: hackathon-kit/templates/REQUIREMENTS.md) 에 옮겨라.
- 번호 항목 1개 = 1행. "해야 합니다 / 포함해 주세요 / 하지 않습니다 / 금지" 가 들어간 문장도 각각 1행.
- 열: 화면 / API / 테스트 / 문서. 지금은 전부 × 로 두고, 비고에 담당자 확인이 필요한 것과 가정을 적어라.
- 산출물 표(실행 안내 파일명·양식, AI 협업 답변, Dockerfile, .env.example, 데이터셋 변형본, 내보내기 스키마)를 채워라.
- 운영 규칙(정원·시각·대상·제외) 문장은 따로 표로 뽑아라: 규칙 | 확인 방법 | 경계(같을 때 허용?) — 이건 $rule-check 의 입력이다.
코드는 쓰지 마라. 끝나면 행 수와 "확인 필요" 목록만 보고해라.
```
이후: 기능 하나 끝날 때마다 "R<번호> 상태 ○/△/× 로 갱신해라" 를 붙인다. 100분 체크포인트는 이 표로 한다.
