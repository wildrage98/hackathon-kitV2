# AI_COLLABORATION

> 과제가 준 질문 양식을 그대로 옮긴다. 답은 **사실**로 — 파일·함수·숫자·로그 경로·시각.
> 제출 후 확인 문제는 이 파일의 문장을 인용해 "받아들인 것 / 고치게 한 것 / 버린 것 / 근거" 를 묻는다.
> 정책·결정에는 이름을 붙이고(예: "조건부 도보 정책"), 각 답에 네 가지가 보이게 쓴다. `(채움: …)` 은 전부 지운다.

## Q1. 구현 과정에서 발생한 가장 까다로운 엣지케이스 또는 장애 시나리오는 무엇이었으며, 어떻게 해결했는지 설명해 주세요.

(채움: 현상 → 원인 → 조치(코드 위치) → 재발 방지(테스트 이름). AI 첫 제안 중 받아들인 것 / 고치게 한 것 / 버린 것)

## Q2. AI가 생성한 코드를 실제 프로젝트에 반영할 때, 엔지니어로서 가장 중요하게 검증해야 하는 항목은 무엇이며 그 이유는?

(채움: 경계값 / 실패 경로 / 숨은 가정 숫자 / 외부 의존·비밀값 — 이번 과제에서 실제로 한 것 1개씩, 근거 파일·테스트명·명령 결과)

## Q3. 이번 과제에서 AI와 함께 복잡한 문제를 해결했거나, AI의 한계를 본인이 직접 극복한 구체적 사례를 작성해 주세요.

(채움: 정책 이름 → AI 첫 결과의 숫자 → 내가 본 문제 → 지시한 수정(코드 위치) → 결과 숫자 → 확인한 테스트·명령. 받아들인 것 / 고치게 한 것 / 버린 것 각 1개 이상)
