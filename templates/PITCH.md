# PITCH — 3분 발표 (선정되면 준비 시간이 없다 → 제출 전에 채워 둔다)

재료는 전부 HOW_TO_RUN(대표 결과 · 설계 기준 · 조건을 바꾸면 · 검증함/가정함/미구현)에서 옮긴다. 새로 만들지 않는다.
말할 때: 숫자 3개 이하, 화면은 실제 동작 1개, 한계는 내가 먼저.

| 순서 | 시간 | 한 문장 | 보여줄 것 |
|---|---|---|---|
| 1. 문제 | 20초 | 누가 / 무엇 때문에 / 어떤 손해를 보고 있었다 (담당자가 말한 사례 1개) | — |
| 2. 기준 | 30초 | 우선순위는 A > B > C 로 잡았고, 숫자 기준은 담당자 확인값 / 내 가정을 구분해 화면에서 바꿀 수 있다 | 조건 입력 화면 |
| 3. 동작 | 50초 | 데이터 적용 → 생성 → 결과 → 사용자 화면 (클릭 3번 이내) | 실제 화면 |
| 4. 결과 | 30초 | 대표 숫자 2~3개 (현행 대비 또는 조건 변경 전후) | 지표 |
| 5. 검증 | 30초 | 규칙은 생성 코드와 별도 검증기로 다시 셌다 — N건 검사 위반 0, 일부러 깨뜨린 결과는 잡힌다, 오류 데이터는 거부하고 기존 상태를 유지한다 | 검증 배지 / 오류본 거부 |
| 6. 한계·다음 | 20초 | 검증 못 한 것 1개, 가정 1개, 현장에 넣으려면 다음에 확인할 것 1개 | — |
