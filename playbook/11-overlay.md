# 11. Overlay 불량 원인 장비 분석 — 현업에게 물을 것 · 데이터 · 분석 · 함정

Overlay = 포토 공정에서 현재 층 패턴이 아래 층 패턴과 어긋난 정도(nm, X·Y). 스펙을 넘으면 재작업(rework) 또는 수율 손실.
목표는 "어느 장비(스캐너·척·트랙·앞 공정 설비·챔버)가 원인인가"를 **근거와 함께 순위로** 내는 것.

## 1. 어휘
| 말 | 뜻 |
|---|---|
| 스캐너(노광기) / 척(chuck 1·2) / 레티클(마스크) | 노광 장비 / 웨이퍼를 올리는 판(장비당 2개가 흔함) / 회로 원판 |
| 트랙 | 감광액 도포·현상 장비 (스캐너와 한 쌍) |
| 현재 층 / 기준 층(reference layer) | 지금 찍는 층 / 정렬 기준이 되는 아래 층 — **기준 층을 찍은 스캐너**도 원인 후보 |
| 장비 매칭(MMO) / 전용(dedication) | 서로 다른 스캐너 간 오차 / 같은 로트를 같은 스캐너로만 보내는 운영 |
| 필드(샷) / intra-field · inter-field | 한 번 노광 영역 / 필드 안 오차 · 웨이퍼 전체 오차 |
| 보정 항 | translation(이동) · rotation(회전) · magnification(배율) · 고차항 — 어느 항이 큰지가 원인 단서 |
| 잔차(residual) / mean+3σ | 보정 후 남는 오차 / 흔한 판정 지표 |
| APC · R2R | 로트 간 자동 보정 — 보정값이 튀면 그것도 원인 |
| 계측기(overlay tool) / TIS | 측정 장비 / 측정기 자체 오차 — **측정기가 원인일 수도** |
| rework | 감광액 벗기고 다시 노광 — 재작업 로트는 이력이 2번 |
| 앞 공정 영향 | CMP · 식각 · 증착 · 열처리(anneal)가 웨이퍼를 휘게(bow/warp) 해 overlay 를 악화 |
| PM · 부품 교체 · 렌즈 히팅 · 척 오염 | 시점성 원인 — "언제부터"가 핵심 |

## 2. 현업에게 물을 것 (우선순위 순, 3~5개씩 묶어서)
**묶음 1 — 정의 (이게 없으면 시작 못 함)**
1. 불량의 정의: 어떤 값(X, Y, |X|·|Y| 최대, mean+3σ, 잔차)이 얼마를 넘으면 불량인가? 스펙과 같을 때는?
2. 판정 단위: 측정점 / 필드 / 웨이퍼 / 로트 중 무엇이 불량 1건인가? (웨이퍼에 불량 점이 1개면 웨이퍼 불량?)
3. 층·제품마다 스펙이 다른가? 어디에 적혀 있나?
4. 분석 대상 기간과 "언제부터 나빠졌다"고 느끼는 시점이 있나?
5. 결과를 누가 보고 무엇을 결정하나? (장비 세우기 / PM / 로트 홀드 / 추가 계측)

**묶음 2 — 원인 후보 범위**
6. 원인 후보는 어디까지인가: 현재 층 스캐너·척·트랙 / 기준 층 스캐너·척 / 레티클 / 앞 공정(CMP·식각·증착·열처리) 설비·챔버 / 계측기
7. 장비 **단독**만 보면 되나, **조합**(현재 스캐너 × 기준 층 스캐너, 스캐너 × 척)도 봐야 하나?
8. 한 로트가 같은 공정을 여러 장비로 나눠 탈 수 있나? 웨이퍼 단위 이력(슬롯·척)이 있나?
9. 재작업 로트는 어떻게 세나(제외 / 마지막 것만 / 둘 다)?
10. 이미 알고 있는 원인·조치 이력(PM, 부품 교체, 레시피 변경)이 데이터에 있나? 그 시점 전후 비교가 필요한가?

**묶음 3 — 판단 기준 (숫자)**
11. "원인 장비"라고 부르려면 근거가 어느 정도여야 하나: 불량률 차이 몇 배? 최소 표본 수(로트·웨이퍼 몇 개 이상)?
12. 오탐(멀쩡한 장비를 세움)과 미탐(원인 장비를 놓침) 중 무엇이 더 비싼가?
13. 원인이 하나라고 가정하나, 여러 개일 수 있나? 상위 몇 개를 보여주면 되나?
14. 결측·측정 실패·이상값(센서 오류 수준의 큰 값)은 제외인가 불량인가?
15. 정답(실제 원인 장비)이 있는 검증용 사례가 있나? 없으면 무엇으로 맞았다고 인정하나?

**묶음 4 — 운영·화면**
16. 지금은 이 분석을 어떻게 하나(엑셀 피벗 / 엔지니어 감)? 얼마나 걸리고 무엇이 제일 불편한가?
17. 화면에서 꼭 봐야 하는 것: 장비 순위표 / 시간 추이 / 웨이퍼 맵 / 로트 목록 / 근거 숫자
18. 조건(기간·제품·층·스펙)을 바꿔 다시 분석해야 하나? 새 데이터가 들어오면?
19. 내보내기 형식(검증에 쓰는 필드)과 순위 동률 처리
20. 범위 밖으로 둘 것: 실시간 연동, 자동 장비 정지, 보정값 계산

없다고 하면: "X로 가정하고 화면에서 바꿀 수 있게 두겠습니다" → 확정 → AGREEMENT.

## 3. 데이터 (예상 형태 — README 로 확인)
- overlay 측정: lot · wafer · (field/point, x·y 좌표) · ovl_x · ovl_y · layer · 측정 시각 · 계측기
- 공정 이력: lot(·wafer) × step × equipment × chamber/chuck × recipe × 시작·종료 시각
- 마스터: 장비(종류·라인) · 스텝 순서 · 스펙(층·제품별) · 레티클
- 이벤트: PM · 부품 교체 · 알람 · 레시피 변경
- 먼저 확인: 키(lot·wafer) 가 두 파일에서 같은 형식인가 / 측정 1건이 이력 몇 행과 붙는가(1:N 폭증) / 재작업 중복 / 시각 형식·타임존

## 4. 분석 순서 (설명 가능한 방법만)
1. **불량 라벨**: 확정된 정의로 웨이퍼(또는 로트)마다 0/1 + 대표값(mean+3σ 등). PARAMS 로 노출.
2. **스텝별 공통성 분석**: 스텝마다 장비(·챔버·척)별 `불량 수 / 통과 수 / 불량률 / lift(전체 대비) / 표본 수` → `groupstats.rate_by`, `rank_factors`
3. **유의성**: 그 장비 vs 나머지 2×2 표 → `chi_square`. 표본 적으면 "판단 보류"로 표시(순위에서 내리되 숨기지 않음).
4. **순위 점수**: lift × 유의성 × 최소 표본 충족. 동률은 장비 ID 순(결정적).
5. **조합**: 현재 스캐너 × 기준 층 스캐너, 스캐너 × 척 → `crosstab`. 단독보다 조합의 lift 가 훨씬 크면 매칭 문제.
6. **시간**: 원인 후보 장비의 일별 불량률·평균 overlay 추이 → `spc.imr_limits`, `svgchart`. PM·교체 시점 전후 비교.
7. **방향·패턴 단서**: X 만 / Y 만 / 특정 척만 / 웨이퍼 가장자리만 나쁜지 — 근거 문장에 넣는다.
8. **교란 점검**: 그 장비가 특정 제품·층·기간만 처리했는지(제품별로 나눠도 순위가 유지되는가).
9. **검증**: 정답이 있으면 Top-1·Top-3 적중. 없으면 원인을 심은 합성 데이터(특정 장비 로트에 +오차)로 찾아내는지 + 원인 없는 데이터에서 "뚜렷한 원인 없음"이 나오는지.

## 5. 결과에 꼭 넣는 근거 (판정마다)
`스텝 · 장비(·척/챔버) · 통과 로트/웨이퍼 수 · 불량 수 · 불량률 · 전체 불량률 · lift · p값 · 기간 · 대표 불량 로트 3개 · 판단(원인 유력 / 의심 / 보류-표본 부족)`

## 6. 규칙 검증기(verify)에 넣을 것
- 불량 수 합 = 라벨 합 (스텝마다) / 장비별 통과 수 합 = 그 스텝을 거친 대상 수
- 불량률·lift 재계산 일치 / 순위가 점수 내림차순 / 최소 표본 미만은 "보류"
- 이력에 없는 장비·로트가 결과에 없음 / 재작업 처리 규칙 준수 / 스펙 경계(같을 때) 일관

## 7. 함정
- 측정 × 이력 조인으로 행이 불어나 불량이 중복 계산됨 → 단위를 먼저 고정하고 `distinct`
- 표본 3개 중 2개 불량 = 67% → 1위로 올리면 오탐. 최소 표본과 검정
- 물량이 많은 장비는 불량 **수**가 많을 뿐 → 반드시 **률**과 lift
- 여러 스텝을 한꺼번에 비교(다중 비교) → 우연히 유의한 것이 나온다. 상위는 시간 추이·조합으로 재확인
- 원인이 기준 층 스캐너인데 현재 층만 봄 / 척을 안 나눔
- 계측기 한 대만 값이 높음 → 장비가 아니라 측정 문제
- PM 이후에만 나쁜데 전체 기간 평균으로 희석 → 기간을 나눠 본다
- 재작업 로트의 앞 이력을 원인으로 셈
- 상관을 원인으로 단정 → 문구는 "원인 유력(근거: …)", 확인 방법(장비 분리 투입·PM 점검)을 같이

## 8. 모듈 · 뼈대
`csvschema`(열·참조) → `dbcore` → `groupstats`(rate_by · rank_factors · chi_square · crosstab) → `spc` · `stats_detect` → `verify` → `report` · `svgchart`.
서비스형이면 `new_webapp.sh` 의 `engine.run`(라벨 → 공통성 → 순위) · `view`(순위표 + 추이 + 근거) · `verify`. PARAMS: 스펙, 판정 단위, 최소 표본, 기간, 제품·층 필터, 상위 N.

## 9. HOW_TO_RUN 훅에 쓸 문장 재료
- 구조 선택: 통계 기반 공통성 분석을 택함 — 블랙박스 모델은 근거를 설명 못 하고 표본이 적어 버림
- 조건을 바꾸면: 스펙을 조이면 불량 수↑·순위 안정성 / 최소 표본을 올리면 보류↑·오탐↓ (측정값으로)
- 가정: 판정 단위, 재작업 처리, 최소 표본 — 누가 정한 값인지

## 10. 성분 분해 · 시그니처 — `kitlib/overlay.py`
장비 순위(§4)와 별개로, 웨이퍼마다 **어느 성분이 큰지**를 근거 문장에 넣는다.
- 모델 (`fit_linear`): `wafer6` dx = Tx + Mx·x − Rx·y, dy = Ty + My·y + Ry·x / 필드 내 좌표(fx, fy)가 있으면 `wafer10` (+ mx·fx − rx·fy, + my·fy + ry·fx). 회전 = (Rx+Ry)/2, 직교성 = Rx − Ry. **좌표 단위·부호 규약은 현업 확인** 후 HOW_TO_RUN 에 기록
- 측정점이 부족하거나 한 줄 위에 있으면 분해하지 않고 `fit_error` 표시, 판정(\|mean\|+3σ)은 계속
- ADI(현상 후, 재작업 가능)인지 AEI(식각 후)인지 묻는다 → ADI 면 식각 전에 잡는 것이 가치

| 우세 성분 / 패턴 | 원인 후보 (확정 아님) |
|---|---|
| 평행이동 Tx·Ty, 평균이 한쪽으로 치우침 | 정렬, APC 보정값 |
| 배율 Mx·My | 열(웨이퍼 팽창), 보정값 |
| 회전·직교성 Rx·Ry | 웨이퍼 로딩·정렬, 스테이지 |
| 필드 내 mx·my·rx·ry, 필드마다 같은 패턴 | 레티클, 렌즈 |
| 가장자리·고차 잔차 (`radial_profile` 바깥 구간만 큼) | 앞 공정 변형(증착 응력·CMP·열처리), 척 가장자리 |
| 특정 척만 | 척 |
| 사이트 몇 개만 튐 | 계측(flyer), 마크 손상 |
평균 편향 = 보정 문제, 산포 = 장비·공정 불안정 → 3σ 하나로 합치지 않는다. X·Y 따로.

flyer: 현업 기준이 없으면 제안 — 중앙값 ± 5·MAD(×1.4826) (`flag_flyers`), 제거 수·위치를 결과에 남긴다.

```python
from kitlib import csvio, overlay, groupstats
rows, _ = csvio.read_csv("data/overlay.csv")                       # wafer, x, y, dx, dy (+ fx, fy, 이력 컬럼)
summ = overlay.wafer_summary(rows, wafer_col="wafer", spec=SPEC, flyer_k=5,
                             keep_cols=["lot", "scanner", "chuck", "reticle", "ref_scanner", "ref_chuck"])
# summ: 웨이퍼별 n, n_flyer, raw_x_m3s, raw_y_m3s, res_x_3s, res_y_3s, Tx..Ry, rotation, non_ortho, fail
rank = groupstats.rank_factors(summ, ["scanner", "chuck", "reticle", "ref_scanner", "ref_chuck"],
                               flag=lambda r: r.get("fail"), min_n=5)
top = overlay.contributions(summ[0], radius=150, residual_3s=summ[0].get("res_x_3s"))  # [{term, size, hint}]
svg = overlay.vector_map_svg([r for r in rows if r["wafer"] == summ[0]["wafer"]], title=summ[0]["wafer"])
```

HOW_TO_RUN 훅 문장 (그렇게 만들었을 때만)
- 구조 선택: 선형 성분 분해는 로봇 좌표계 캘리브레이션과 같은 문제 — 측정점 쌍에서 평행이동·회전·스케일을 최소제곱으로 추정하고 잔차를 따로 봤다
- 잘못된 입력: 측정점 부족·한 줄 위 → 분해 생략(fit_error), 판정은 유지
